HOW TO PREVIEW
1. Extract the ZIP file.
2. Open index.html in a web browser.
3. For development, open the folder in Visual Studio Code and use Live Server.

IMPORTANT PERSONALISATION BEFORE SUBMISSION
1. Add your own profile photo. Replace the BP placeholder in biodata.html with an img element and your photo in assets/.
2. Add your own video file named portfolio-video.mp4 inside videos/.
3. Update the sample timetable to match your real weekly timetable.
4. Review all project descriptions and add real screenshots / links where available.
5. Add your preferred contact or social media details if required.
6. Test all five pages on desktop and mobile.

PUBLISHING
You can publish the extracted folder using a free static hosting service such as GitHub Pages or Netlify. Upload the whole website folder/repository and copy the public website URL into your assignment submission.

NOTE ABOUT THE FORM
The comments form currently demonstrates front-end validation and a success preview only. It does not store or email submissions. A server-side form service or backend is needed for real message delivery.

NOTE ABOUT FLASH
Adobe Flash is discontinued and unsupported in modern browsers. This project uses CSS and JavaScript animations to achieve the requested animated visual effect with current web standards.
